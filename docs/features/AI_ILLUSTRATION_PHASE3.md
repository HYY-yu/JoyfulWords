# AI 插图第三阶段：信息图

入口：文章详情 → AI 工作室 → AI 插图 → 信息图。

## 当前合同（验收调整后）

- 复制旧“生成信息图”弹窗的两栏布局：左侧编号来源区与参数区，右侧生成按钮、历史、进度和图片网格；沿用来源卡片、1–5 张分段按钮、方向和语言分段按钮。
- 整篇模式用户选择最多 1–5 张（新面板默认 5）；AI 先分析已保存文章并拆成语义 HTML 卡片，再按各张内容生图。张数为上限，不强凑。选段模式只生成一张。
- 设计风格和配色仅显示已锁定摘要；删除视觉风格、装饰密度、自由指令控制。配图保持待开放。
- 全文最多 60,000 字，选段最多 20,000 字。提示词禁止编造，分析摘录必须真实匹配来源；用户仍需核对结果。
- API 仍为 illustration 独立链路；旧 infographic 业务和历史保留。v67 使用父批次/子图片，前端同时兼容此前 is_batch=false 的付费单图。
- upfront 展示每张单价和最大费用，余额检查按上限。分析不额外扣用户积分，成功子图各自结算，部分失败不影响已成功图片。
- 批次 pending/analyzing/processing 时轮询；succeeded/partial/failed/empty 停止轮询。网络连续三次失败显示刷新；关闭重开恢复批次和所有子图。
- cards 展示逐图状态、来源摘录与理由、完整 PNG、放大和下载。HTML 仅在服务端持久化/提示词使用，不作为可执行 DOM。
- 每次重新生成使用新键；同请求网络重试复用键。历史选择恢复来源、上限、方向和语言。
- 封面预设、标题位置、前端裁切、单图 loading 均保持原实现。
