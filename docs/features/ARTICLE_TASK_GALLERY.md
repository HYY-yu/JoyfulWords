# 文章任务画廊

入口位于编辑器 AI 工作室的任务进度标题下方，替换原说明句，使用与“清除已完成”相同的小型文字按钮。

弹窗顶部居中展示当前有效设计风格、配色名称和色块；下方按创建时间倒序排列已完成视觉结果，桌面采用三列图片网格，窄屏降为两列/单列。每张图片单独占一个网格单元，隐藏外部标题和时间。顶部轻量黑色渐变透明蒙版（顶部 18.75%、中段 8.75% 到全透明）放置类型和保存素材、下载图标按钮，点击图片本身放大，键盘及触屏均可直接操作。当前支持封面、信息图、配图、历史图片及图表，暂不展示 PPT。当前设计不代表历史图片已经重绘。

通过 `GET /api/taskcenter/gallery?article_id=...` 独立分页加载，默认每页 12 项，加载更多可访问其余结果；后端不应用进度隐藏标记，因此“清除已完成”不会清空画廊。用户归属由后端验证。

图片缩略图以 4:3 填充展示，查看大图保持完整内容；蒙版可直接保存素材或下载，封面按冻结尺寸输出，其余图片按原始尺寸输出，缩略图裁切不影响文件。点击放大后复用 CoverPreview。图表以 640×480 逻辑画布渲染存储的 JoyChart spec，再整体等比缩放到网格，避免坐标轴、图例和固定边距挤压绘图区；缩略图导出保留完整画布分辨率，同样支持放大、保存素材和 PNG 下载；不重新生成，也不触发扣费。图片加载失败、风格查询失败、画廊请求失败提供独立错误/重试状态。关闭弹窗会中止未完成请求，切换文章不复用旧数据。

验证包括类型检查、目标 ESLint、任务中心 PostgreSQL 回滚测试及中英文浏览器验收。临时预览使用现有配图和模拟分页/图表，验收后删除；不改真实文章、素材库或计费数据。
