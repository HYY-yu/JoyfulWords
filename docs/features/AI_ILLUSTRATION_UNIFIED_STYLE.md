# AI 插图收尾：统一风格与素材库

## 入口与风格

- 文章列表顶部、任务中心旁的工具栏提供六种设计风格、五个色系，提交到 `PUT /illustrations/design-preference`。
- 账户选择适用于全部新旧文章后续生成。历史图片不重新生成，不更改原快照。
- AI 插图移到原 AI 信息图位置；旧 AI 信息图与 AI 封面图卡片隐藏，原弹窗、处理函数、API 和任务历史保留。
- 插图弹窗只保留封面、信息图、配图三类，不再显示风格选择、锁定摘要和内部生成参数。

## 图片工作区

封面采用与信息图、配图一致的左设置、右结果布局，保留尺寸、标题位置、历史版本、错误恢复和轮询。窄屏纵向排列；尺寸与标题位置使用可点击预览控件。说明文案中英文同步精简。

每张结果图操作栏统一提供“加入素材库”和“下载”。保存当前 Canvas 输出的 PNG，封面切换尺寸时保存当前裁切版本；信息图和配图按实际尺寸完整保存。复用预签名上传、上传确认及 `POST /materials`，成功后触发 `joyfulwords-materials-refresh` 并禁用当前视图中的重复保存。该操作不调用生图服务。

## 后端与部署

先执行 v69，再启动新版 API。新增账户偏好表；文章绑定从每篇一条改为不可变版本。读取设计不写库，未物化版本 id 为 0、状态 ready；生成事务才创建实际版本、业务记录及 job。旧幂等请求仍返回原快照。Worker 的付费任务处理合同不变。

## 验证

- TypeScript、目标 ESLint、插图状态和裁切单测。
- Go 插图模块及路由测试；PostgreSQL 回滚测试验证新旧文章、三类产物、非法配色、归属检查、历史快照和幂等重放，不调用 Provider。
- 临时隔离 UI 预览验证中英文、桌面/窄屏、风格应用与三类素材保存成功状态。预览使用测试数据及模拟上传，验收后移除，不等同于登录账户的真实 R2 上传验收。

## 逐图任务进度

任务中心与编辑器进度列表展示三种独立类型：封面、AI 信息图、配图。分析时先展示一条分析项，拆图后按每张图片展示，不重复展示父批次。详情提供阶段、积分/结算状态、图片预览、加入素材库与下载。提交后立即通知任务列表刷新；后台轮询持续更新。旧图像任务历史保留。

部署补充：执行后端 v70 后重启 API 和 Worker。回滚测试覆盖三类型的列表、阶段、归属、筛选、分页、隐藏和 orphan job；结算测试覆盖成功重放、失败不扣费和批次不扣费。
