# 思维导图配色适配

思维导图仅适配统一配色，保留原有节点、连线、字体、圆角、间距、背景网格、阴影与交互效果。移除六种风格的几何和材质分支，连线恢复 Mind Elixir 默认实现。

复用 `fetchArticleDesign`，优先读取文章设计快照，无绑定时使用账户设置；无设置时采用简约商务绿色。六种风格对应的五个色系仍可提供色板，但不改变导图设计。中心、文字、节点底色、背景、边框、选中状态和分支使用语义配色。

打开面板、切换文章、收到 `DESIGN_CHANGED` 时重新加载。加载失败显示重试，不静默替换配色。渲染配色不会覆盖已有节点颜色元数据，文字、备注、方向与折叠状态继续保留。

XMind 沿用原有结构导出，不新增视觉样式导出。此前六风格预览已删除，避免展示不再采用的设计。

验证：`node --import tsx --test lib/mindmap/mindmap-design.test.ts` 覆盖 30 套配色下原有几何参数不变，以及编辑数据往返；另执行 ESLint 和 TypeScript 检查。
