# AI 插图第一阶段

文章详情 → AI 工作室 → AI 插图。组件位于 `components/article/illustration/`，
新 API client 位于 `lib/api/illustrations/`，不复用旧封图/信息图业务组件。

- 初次打开从 `/illustrations/catalog` 与 `/illustrations/articles/:id/design` 读取目录和绑定。
- 未绑定时提供六种风格、五种色系及配色示意预览。预览明确标注不是 AI 成品。
- 用户勾选不可更改说明后确认；服务端持久化快照并启动免费设计准备任务。
- 已绑定时只展示快照与锁定标识，刷新/重开恢复 `pending/processing/ready/failed`。
- 准备中定时查询状态，关闭弹窗取消读取；连续三次网络错误显示刷新入口。
- 准备失败可调用 `/design/prepare` 重试，不重新选择或覆盖风格。
- 封面、信息图、配图只展示职责和待开放状态；第一阶段不提供生成参数或调用模型。
- 原有封图和信息图入口、历史暂时保留；articles 顶部工具栏不改。
- 所有新增文案同时在 `zh.ts` 和 `en.ts` 定义。

## 验收

1. 风格切换时，五个色系圆点与右侧配色示意使用对应风格色值。
2. 未勾选锁定说明时无法提交；提交中禁用修改与弹窗关闭。
3. 提交后只读，后台准备完成显示“设计已就绪”；刷新仍保持相同设计。
4. 三种插图类型可切换说明，生成按钮均不可用。
5. 新接口异常时显示刷新入口，不伪造成功状态。

需先执行后端 v62、v63 迁移，并运行包含新代码的 API 和 Worker。
