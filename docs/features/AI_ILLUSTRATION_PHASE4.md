# AI 插图第四阶段：配图

入口：文章详情 → AI 工作室 → AI 插图 → 配图。

## 产品合同

- 基本无文字的场景表达文章视觉 IP，与封面延续相同意象、主体比例、材质、光影和配色。信息解释仍交给信息图。
- 来源：已保存全文 / 当前选区或提供内容；方向：横向 / 纵向 / 方形。
- 全文最多 1–5 张，默认 5；选区一张。提交前展示单价与费用上限，仅成功图片结算。分析不额外扣用户积分。
- 设计风格和配色只读，没有语言、模型、装饰密度或自由提示词选项。
- 使用与信息图一致的两栏交互：左侧来源和方向，右侧批次、进度、历史与图片。逐图放大、PNG 下载、来源与理由可查看。
- 配图直接展示完整图；不执行封面裁切。封面现有尺寸选择、标题位置和裁切体验保持。

## 数据与恢复

- 独立 `/illustrations/artwork-options`、`/articles/:id/artworks`、`/artworks/:id`。
- v68 新表 `illustration_artworks` 保存分析批次及子图；`illustration_visual_profiles` 保存共享不可变视觉设定。新封面与配图都使用该设定。
- 服务端优先选择同文章同绑定最新成功封面作为参考；无封面时使用首张成功配图，否则只使用设定。每次输入冻结参考 ID/URL，用户不能覆盖。
- 快照含来源、正文、标题、方向、上限、设计、视觉设定、参考图；后台冻结分析模型、图片模型、Provider、单价、场景和提示词。
- pending/analyzing/submitting/processing 轮询；succeeded/partial/failed/empty 停止。关闭重开恢复；网络连续失败可刷新。提交重试沿用幂等键。
- 分析场景 JSON 不渲染 HTML；来源摘录按普通文本展示。空场景不生图，部分失败保留成功图。
- 本阶段未收敛旧入口；旧历史和业务不变，不扩展 PPT、图表、脑图、公众号或 Word。

### 富文本来源与摘录校验

信息图和配图共用正文提取：整篇文章从冻结 HTML 提取文本，解码 HTML 实体，保留行内标签两侧的连续正文，并将段落、换行与 Unicode 空白规范为单个空格；忽略脚本、样式、模板、hidden 元素和标签属性。选中文本按纯文本处理，不解释其中的尖括号或实体字面量。分析模型收到该规范正文，摘录、锚点及配图 source_term 均在同一正文上校验；不允许虚构摘录，也不将相邻段落无分隔拼接。原始 input_snapshot.text 和历史 source_text 保留不变，实际分析提示词继续冻结。此修复不重试既有失败记录，也不触发生图或结算。
