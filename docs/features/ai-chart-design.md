# AI 图表自动设计主题

图表无需选择主题。`lib/echarts/joy-chart-theme.ts` 统一解析样式与配色，`JoyChartRenderer` 统一加载设计并负责预览、PNG 导出。没有新增依赖、数据库字段或 HTTP 接口。

## 设计来源

1. 带 articleId 的图表读取 `/illustrations/articles/:id/design`，优先使用文章 binding.snapshot。
2. 未绑定文章、独立图表读取 `/illustrations/design-preference`。
3. 游客不调用认证接口；无偏好时使用与 v62 目录一致的简约商务绿色默认主题。
4. 个人设计变更事件 `illustration-design-changed` 触发重新读取。文章绑定优先于个人偏好。

只合并进行中的同用户、同文章、同刷新版本请求；不长期缓存设计，不跨用户共享结果。加载与错误期间遮挡图表并禁止导出；错误有中英文重试提示和 Warn 日志。旧请求的结果不会覆盖新上下文。

## 风格合同

| 风格 | 图表表现 |
| --- | --- |
| 简约商务 | 2px 圆角、2px 线条、圆点、清晰网格 |
| 杂志叙事 | 衬线标题、直角柱、方形点 |
| 手绘插画 | 纸色背景、虚线网格、空心点 |
| 萌系 Q 版 | 12px 圆角、3.5px 线条、大圆点 |
| 高级毛玻璃 | 可导出的透明渐变柱、菱形点 |
| 极简光影 | 弱网格、隐藏分类轴线、轻阴影 |

颜色直接使用设计快照的 chart、background、surface、text、muted_text、border。未知风格使用商务几何，但保留快照配色；空 chart 色列回退默认色列。图形不使用抖动或强制平滑，数据比例与原值不变。横向柱的圆角方向同步旋转。

## 入口与兼容

工具箱、任务中心、文章图库缩略图与放大图均使用同一渲染器。文章入口必须传 articleId。

`display.style.theme` 与 `display.bar.borderRadius` 保留旧 HTTP 合同，前端不再显示选择或调整入口，也不用于渲染；历史任务无需迁移，数据和其他布局设置保留。排序、堆叠、柱宽、标题位置、图例、折线平滑及面积开关仍有效。

设计在渲染时读取，不写入图表任务快照，因此重新打开旧图表会应用当前有效设计；已经插入文章的 PNG 是静态图片，不自动重绘。导出先同步最新 option，关闭动画，再使用同一背景色以 2 倍像素导出。

## 验证

`node --import tsx --test lib/echarts/*.test.ts` 覆盖风格和图表类型、历史 theme 无效化、数据不变、横向柱、设计优先级、错误传播和请求隔离。
